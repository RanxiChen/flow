# Breeze GAPBS：2026-09-18 首轮板级结果

来源：用户提供的 KCU105 串口输出。平台为单 hart Breeze，100 MHz，2 GiB DDR4，
SD + FASE FPGA 基线 29ee514；软件配置 b2a895b，Buildroot musl、GCC 14.4.0，
GAPBS 源码 b5e3e19c2845f22fb338f4a4bc4b1ccee861d026，OpenMP 构建。
Linux 使用内嵌 initramfs，SD 仅用于 BIOS 加载。

建议环境为 OMP_NUM_THREADS=1、OMP_DYNAMIC=FALSE；本次粘贴未包含环境变量输出，
因此本条记录不独立确认实际 OpenMP 线程数。单 hart 不等于程序只创建一个线程。
