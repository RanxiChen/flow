## 实现决定与合同边界

- **A1**：4写bank×6读副本，inline SV 1W1R同步READ_FIRST BRAM，字节写使能、同一逻辑写广播、无阵列复位；寄存bank选择。有效读只在冒险检查通过后发出，断言同址实际写不能同时被有效读消费。整数/cross/store增加请求返回阶段；操作数首次停顿后保持，避免共享读口覆盖BRAM输出。SEW64原迭代乘加保留。
- **A2/A5**：scoreboardDepth独立参数默认16，队列4/2/2/2/2；满表/满目标队列阻塞有序分派，burst不占记分板。没有隐藏加深队列。
- **A4**：VIQ默认8，显式1W1R异步LUTRAM FIFO、payload不复位，保留commit容量预留；只保存执行所需字段，vtype8位，rs1仍64位。PA参数默认34位，接口仍RV64，超宽正常翻译响应断言。memoryInflight和区间16。年龄默认8位，以模差符号排序；前端/VIQ头/区间/迟到翻译tag/记分板共同限制活跃跨度小于半空间。kill后的迟到tag也持有年龄租约，避免回绕别名。被动64位年龄零扩展，软件恢复代数编号，未减少配对。
- **A3/A6最终**：返回BRAM输出及按槽号选出的描述符进入弹性寄存级；冒险/写行号/年龄/进度只取寄存元数据。每beat所有piece完成VRF写后归还信用；bufferedBytes含弹性级。记分板按静态条目合并客户端清位，只在沿更新mask；放行只查寄存mask/age，不做同拍旁路。候选7e0d29b额外增加progress寄存，后在148c267删除多余等待：描述符/返回元数据和掩码均已寄存，仍没有BRAM输出或数据位组合进入mask更新。写回数据位不控制握手。
- **共享ALU**：按SEW边界切断字节进位，一套分段加减；一套6级逻辑右移网络按元素边界补零；标量按SEW广播。乘加路径未扩功能。标量move无VRF读取，148c267从寄存描述符直接逐行写回，向量读仍同步。
- **VLSU**：load/store各一套宽循环字节旋转器，输出固定切片，原非对齐/page切分/使能保持。B响应slot FIFO从256缩到16，满时阻止新AW，仍按原B响应释放/归还，不把burst变成指令条目。

v0影子静态索引项未采用：默认rowsPerReg=1时原索引可静态化，无可信默认收益；实际store旋转优化已综合验证。设计第3节的越位、排序、挂载及单元划分未修改；非默认参数探针仅用于诊断。

## 未闭合合同、最好结果与需要设计决策的项目

**P1/P2/P4未闭合，单项面积超标按上表保留；总量收敛不等于R03全通过。** 对候选参数的原始JSON、全部配对CSV及默认性能保留，不推迟producer写回、不忽略排队配对。

P1事件证明连续MAC首读间隔196对为5拍、块边界27对为8拍，而每条权重只有4个读beat。同步读的指令交接拍、单元内顺序和块累加/reset依赖限制吞吐；首寄存器提前写完后等待队列执行也计入P4。控制优化已将P1从70.33%提高到75.17%、最大链接13→11，仍未达95%/4拍。后续真实跨指令操作数流水需明确3.4中同单元“开始执行”边界；不能只改被动事件伪造链接。

P2有序分派遇到2项MAC队列满会停，seq占1条，等待40拍load时提前窗口约3条×4beat，约12/40≈30%。非默认探针86531c6全部匹配Spike：MAC12/SB16 **58.79%**，MAC12/SB24 **70.44%**，MAC2/SB24 **30.55%**；链接最大3/10/3拍，全部P5提前。加深SB单独无收益，增加容量也未证明90%；不把参数探针当默认通过证据。

需要用户决定的结构方向：允许已提交VIQ中的后继load在前面的MAC队列满时提前建立请求（改变3.2/3.4有序分派/越位边界，必须保留区间、提交和信用检查），或重新批准MAC/记分板容量并重算面积/年龄/在途窗口；当前未实施。40拍×1beat/拍至少需约10条4-beat权重的有效提前量，实际容量还需覆盖累加/reset、翻译和挂载间隔，不把下界当达标配置。

单项面积：记分板32位多读/写mask、年龄选择和五客户端判断仍昂贵；VRF包含4bank×6副本的读选择、共享执行读口映射、仲裁/v0影子；ALU包含共享移位/分段算术及操作数保持/选择。可继续试实际端口范围裁剪、mask编码/比较流水等实现手段，但本次未证明单项预算闭合。若降低读副本/写bank或改变并发客户端结构，需要修改3.6/3.4并重新定吞吐与冲突规则，当前保持冻结组织。
