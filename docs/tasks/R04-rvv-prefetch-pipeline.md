## 2. 链接延迟口径（替换 R02/R03 的 P4 口径）

R02 的 P4 按“vle 写完第一个寄存器 → vqdot 开始读”计时。预取生效后，load 远早于 vqdot 完成，这个差值会变成访存提前量，不再表示链接代价。R03 报告也指出等待队列的时间被计入了 P4。新口径（设计文档 3.4 节）：

```text
t_ready = max(生产者写完该寄存器的那一拍, 消费者除这一 RAW 外已能开始的那一拍)
链接延迟 = 消费者首次读该寄存器的那一拍 − t_ready
```

“除这一 RAW 外已能开始”：消费者是其单元 sequencer 的当前指令，本单元没有更老指令仍在发读，其他源操作数、WAR/WAW、读口分配都已满足。由 testbench 的被动事件按每拍阻塞原因计算，事件只观察，不进入 RTL 控制。报告附原始 CSV，包含两个时刻及阻塞原因，口径实现写在报告里。R02 `*-pairs.json` 的历史字段保留。
