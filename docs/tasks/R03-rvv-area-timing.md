# R03：RVV 协处理器面积与时序收敛

本任务书交给实现 agent，**直接实现**。依据是 [`docs/rvv-coprocessor-design.md`](../rvv-coprocessor-design.md)（下称“设计文档”），重点是第 4 节的资源与时序预算，以及 R02 综合后更正的 3.2、3.4、3.6 节。实现细节由你决定并写进报告；只有必须改变设计文档第 3 节的结构（越位规则、排序规则、挂载合同、单元划分）时才停下来问。

起点：R02 最终提交 `79f6c5a`。R02 的功能与带宽结果有效，面积 206k LUT、WNS −2.117 ns 不可接受。

## 0. 规则

R02 第 0 节的全部规则继续适用（只在 `feat/rvv-20261005` 上工作；只改 `design/src/main/scala/rvv/`、`design/src/test/scala/rvv/`、`rvv/`、`docs/rvv-*`、`docs/tasks/R03-*`；Alan 上独立工作区、`nice`、不超过半数核；不放宽合同、不对测试特判；证据附提交号、命令、日志；不做形式化）。另外：

1. **第 0 步**：提交并 push 设计文档的修改、R02 任务书中 P4 一行的修改，以及本任务书。
2. 本任务**可以修改** R02 写的 RVV RTL 与测试。已有的 C2 定向用例、C3 随机测试和 Spike 比对只能增加，不能删除或放宽；因流水级变化而需要调整的时序断言，在报告中逐条列出“旧 → 新”及理由。
3. 不新增指令功能。FP、串行执行仍只有框架，R03 不实现。

## 1. 目标

在功能不退化的前提下，把 RVV 协处理器（R02 子集）综合到：

- **LUT ≤ 77k**：设计文档 4.2 节的合计预算 97k 减去 FP 的 20k（FP 尚未实现，预算留给它）。争取 ≤ 60k。
- **100 MHz 下综合 WNS ≥ 0**。
- 各部件不超过 4.2 节的单项预算；超出的部件在报告中单独说明原因和下一步办法。

## 2. 必须做的改动

| # | 部件 | 改动 | 设计文档 |
| --- | --- | --- | --- |
| A1 | VRF | 改为 BRAM 同步读：每个（写 bank，读副本）一组 1W1R 简单双口 BRAM，宽 DLEN；字节写使能；同一逻辑写口广播到该 bank 的全部副本。同址读写模式任选一种并加断言（冒险检查保证不会消费）。综合报告中必须看到 VRF 映射为 RAMB36/RAMB18，**LUTRAM 为 0** | 3.6 |
| A2 | 记分板 | 表项默认 16（参数）；满时分派停住；VLSU 的在途 burst 不占表项 | 3.4 |
| A3 | 冒险判断 | sequencer 本拍是否放行，只用上一拍寄存的掩码与年龄状态；BRAM 输出、返回缓冲输出、写回数据通路不得组合地进入冒险判断或掩码更新 | 3.4、4.3 |
| A4 | VIQ 与前端 | VIQ 改为 LUTRAM FIFO，默认深度 8–16；只存执行需要的字段：vtype 8 bit；地址按平台物理地址宽度（新增参数 `paBits`，默认 34）；年龄号按 log2 宽度；翻译编号的年龄同样收窄。区间表项数不超过 VLSU 访存跟踪上限 | 3.2 |
| A5 | 单元队列 | 默认深度 4/2/2/2/2（访存、ALU、乘加、FP、跨 lane） | 3.4 |
| A6 | 时序 | 控制路径从寄存器到寄存器；高扇出选择信号（如返回槽号，R02 扇出 690）复制或打拍；需要时增加流水级，代价计入链接延迟（≤ 4 拍）与单元延迟 | 4.3 |

除以上必做项外，为了达到第 1 节的目标，你可以自行采取任何不改变第 3 节结构的面积和时序手段，例如：各 SEW 共用一套移位器；VLSU 只保留一套旋转器；把宽比较器打拍；调整参数默认值。每项在报告中写明节省了多少（按综合报告的层级值）。

## 4. 回报

`docs/tasks/R03-report.md`，格式同 R02（提交号、命令、日志、结果表、你决定的实现细节、与设计文档不一致之处、已知限制）。另加一节：**各项改动的面积账**，每项改动前后对应部件的 LUT/FF/BRAM。
