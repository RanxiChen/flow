Radix-4 Booth 编码器

输入 64-bit 乘数 → 输出 33 个系数 ∈ {−2,−1,0,+1,+2}

乘法本质是做一堆加法。朴素做法：乘数 64 bit → 64 行部分积，太多了。

Booth 的想法：每次看乘数的 3 个 bit（重叠 1 bit），一次处理 2 bit 的乘数，产生一个系数。64 ÷ 2 = 32 次，加边界 1 行 = 33 行部分积。砍半。

3-bit 模式系数直觉解释
0000三个零 → 一路平地，不操作
001+10→1 上升，一串 1 的结尾 → 加一次
010+1孤立的 1（两边是 0）→ 加一次
011+2两个 1→升到更高位 → 加 2 倍
100−2两个 0→从高往低降 → 减 2 倍
101−1孤立的 0（两边是 1）→ 减一次
110−11→0 下降，一串 1 的开头 → 减一次
1110三个一 → 一路高台，不操作

系数 ±2 只需要被乘数左移 1 位（免费）。系数为负时：被乘数按位取反 + 末尾补 1（二进制补码）。

部分积生成器 (Partial Product Generator)

33 个系数 × 被乘数 → 33 行 ~130-bit 部分积

每个 Booth 系数驱动一个 MUX，产生一行部分积：

系数部分积输出
0全 0
+1被乘数
+2被乘数 << 1
−1~被乘数（按位取反）
−2~(被乘数 << 1)（移位后取反）

然后左移 2×i 位（因为每组覆盖乘数的 2 bit）。

部分积宽度约 130 bit：64-bit 被乘数 + 符号扩展 + 移位。确切宽度取决于符号处理的 trick（标准实现中约为 128 + 几个校正位）。

CSA 压缩树 (Dadda / Wallace)

33 行 → 多层 3:2 压缩 → 最终 2 行 (sum + carry)

CSA = Carry Save Adder（进位保存加法器）。一个全加器接收 3 个同权 bit，输出 2 个 bit（sum + carry），不传播进位。延迟 = 1 个 FA 的门延迟，与位宽无关。

每层 CSA 把行数压缩到原来的 ~2/3：

33 → 22 → 15 → 10 → 7 → 5 → 4 → 3 → 2

WallaceDadda
策略每层见 3 就压按序列 (2,3,4,6,9,13,19,28,42…) 只在必要时压
FA/HA 数量较多少 ~15-20%
布线规整不规则

你的设计写 Dadda/Wallace，表示两者都可。Chisel 生成时，Dadda 省面积；手工布局时 Wallace 更规整。延迟几乎一样（~8 层 FA）。

4

最终加法器 (CPA — Carry Propagate Adder)

sum + (carry << 1) → 128-bit 乘积

CSA Tree 输出的是"欠条"——进位一直欠着没还。这里用真正的进位传播加法器一次性偿还。

候选：Kogge-Stone（前缀加法，log₂N 延迟，~7 级门延迟 at 128b）、Brent-Kung（省面积）、CLA（分块级联）。

注意 carry 要左移 1 位：CSA 输出的 carry bit 权值是当前列的 2 倍。

结果选择 (输出 MUX)

根据指令类型，取乘积的高 64 / 低 64

128-bit 乘积完整计算出来后，不同指令要不同的结果：

指令操作数符号返回
MUL rd, rs1, rs2有符号 × 有符号product[63:0]
MULH rd, rs1, rs2有符号 × 有符号product[127:64]
MULHU rd, rs1, rs2无符号 × 无符号product[127:64]
MULHSU rd, rs1, rs2有符号 × 无符号product[127:64]
MULW rd, rs1, rs2有符号 × 有符号sign-extend(product[31:0])

无符号操作数：Booth 编码前在最高位补 0（把无符号数当作正的有符号数）。
MULHSU：rs1 用有符号、rs2 最高位补 0 做无符号扩展。
